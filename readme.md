Sorting Visualizer

This project is a sorting visualizer written in Python using the tkinter library. It displays a list of values as vertical bars and animates how different sorting algorithms rearrange the data step by step.

How to Use

Click Generate to create a new random array.
Choose a sorting algorithm from the dropdown menu.
Use the Size slider to change how many bars are displayed.
Use the Speed slider to control the animation speed.
Click Sort to start the visualization.

Implemented Algorithms:

Insertion Sort

Merge Sort

Quick Sort

Heap Sort

The program highlights active elements during sorting to make the process easier to follow.
